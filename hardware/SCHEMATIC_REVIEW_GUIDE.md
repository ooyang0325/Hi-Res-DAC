# Schematic peer-review guide

Review the committed [root schematic](DAC_HPA.kicad_sch) and eight linked sheets in KiCad 10, or start with the [nine-page PDF](DAC_HPA_review_only.pdf). The root is PDF page 1; circuit sheets 1–8 are PDF pages 2–9. Record the Git SHA and sheet/page in every finding.

## Source and automated-check boundary

The v0.9 workbook supplies 1,445 pin rows across 247 workbook nets including NC. The capture contains 1,402 connected pins and 43 no-connect pins. `verify_schematic.py` compares the captured pin/net and MPN/fit properties with that workbook and its explicit overrides. `verify_design_notes.py` checks 947 selected rules, and ERC reports zero violations. These are **consistency checks**. Inspect datasheet pin function, power limits, startup/fault behavior, analog stability and physical pad mapping independently.

[Source reconciliation](SOURCE_RECONCILIATION.md) lists where a checklist or versioned Office document conflicts with the captured decision. A reviewer should test the *reason* for each exception, then report any new discrepancy. Do not silently replace the owner-approved OPA2210 VSSOP, the corrected LED polarity, or the connector maps with an older source value. `generate_schematic.py` rewrites generated schematic files; use a clean checkout and avoid running it in a review workspace unless testing regeneration deliberately.

## Cross-sheet checks to return explicitly

1. **End-to-end path:** USB attach and bridge enable → stable clocks/I²S → DAC and analog rails → output permit/relay → both jacks. Identify any state where an output can connect before rails and offsets are safe.
2. **Protection:** for over-range, low-level persistence, rail loss, hot-plug, short and self-test, trace both channels from detector to muted output. Challenge single-fault and stuck-high/low assumptions using the Spec and Calculation Package. Note the 50 mΩ/jack-contact output-impedance assumption is an engineering estimate until bring-up measures each jack at ≤0.5 Ω.
3. **Source corrections:** verify C102 2.2 µF, R227 at `N2_X201_OUT`, R665 330 Ω, Q622 in permit, U403/U404 DGK VSSOP and D705/D706 polarity against [Source reconciliation](SOURCE_RECONCILIATION.md).
4. **Physical mapping:** compare symbol pin numbers to footprint pads for J101/J701/J702, U202 exposed pad, polarized parts, oscillators and owner-fitted relays. Use [G-3 overlays](G3_OVERLAY_INDEX.md) and [G-4 record](G4_POLARITY_CHECKLIST.md). G-1/G-2 are owner-accepted with raw-log waiver; this waiver does not extend to G-3/G-4.
5. **Assembly split:** check the placed/owner-fitted/DNF classification in the three review CSVs. The 455 JLC-placed lines and 14 lines without LCSC codes are a review snapshot, not an order-ready BOM. Verify the process holds in [PCBA process review](PCBA_PROCESS_REVIEW.md).

For each checked path, report **pass**, **issue**, **needs measurement** or **not reviewed** in the [findings template](REVIEW_FINDINGS_TEMPLATE.md). Include the governing datasheet/table or measured waveform when proposing a change; a clean ERC result alone is not sufficient evidence.
